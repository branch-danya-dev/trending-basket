# Самостоятельный запуск Demo на Windows

Откройте PowerShell в каталоге репозитория. Настройки уже находятся в локальном
`.env`: Demo, ключи, Telegram и `TB_ALLOCATED_CAPITAL_USD=1000`.

## Обычный запуск или восстановление после выключения компьютера

```powershell
.\.venv\Scripts\tb.exe run --mode demo --loop
```

Оставьте окно и компьютер включёнными. Процесс сверяет позиции, стопы и маржу
между ежедневными решениями. После пропущенного времени обработает последнее
дневное закрытие; уже завершённый день повторно не торгует. Вторая копия
на этом компьютере не запустится из-за блокировки. Не запускайте независимые
копии бота с одним ключом и разными каталогами состояния на разных устройствах.

## Если установлен флаг аварийной остановки

Сначала устраните указанную причину. Затем:

```powershell
.\.venv\Scripts\tb.exe run resume
.\.venv\Scripts\tb.exe run --mode demo --loop
```

Первая команда покажет причину, попросит подтверждение и выполнит сверку.
Если сверка или контроль риска не проходят, возобновление будет отклонено.
Удалять `data/live/demo/state.json`, сбрасывать пик или менять выделенный
капитал для обхода остановки нельзя. Для этих команд сообщения в чат не нужны.

## Проверка без торговых заявок

```powershell
.\.venv\Scripts\tb.exe demo check
.\.venv\Scripts\tb.exe run --mode demo --once --dry-run
```

`demo check` отправляет проверочное сообщение в Telegram. Dry-run не отправляет
заявки или сообщения и не меняет торговое состояние.

`--once` выполняет один цикл и завершает процесс. Биржевой стоп остаётся,
но ежедневное сопровождение требует работающего `--loop`. Ctrl+C останавливает
процесс; позиция автоматически не закрывается, подтверждённый стоп остаётся.
Все времена решений — UTC: после 00:03 (03:03 по Москве).
